## Key Design Decisions
- **dryRun: true by default** — Reads from Tally normally but skips all uploads. Safe to test without backend.
- **Mutex** — `syncService.isSyncing` boolean prevents overlapping syncs
- **Session resume** — On startup, in-progress sessions < 2h old are detected (but abandoned since data context is lost after restart)
- **Clock skew detection** — If `last_delta_sync_at` is in the future, resets to 24h ago
- **All groups selected = empty array** — Means "sync everything", avoids storing every group name
- **Parent toggle** — Checking/unchecking a parent group toggles all its children

### Common Issues & Fixes
| Issue | Likely Cause | Fix |
|-------|-------------|-----|
| Company dropdown empty | Tally not running or no company open | Start Tally, open a company |
| Stock groups empty | Wrong company selected or no stock groups in Tally | Check Tally has stock groups defined |
| "Tally module not available" | Module not enabled in config | Check `agent.config.json` → `modules.tally.enabled: true` |
| Sync button does nothing | No company selected | Select a company first in Configuration tab |
| Progress bar stuck | Sync errored silently | Check console/Logs page for errors |
| "Sync already in progress" | Previous sync didn't finish | Wait or restart app |
