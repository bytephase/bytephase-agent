## Bugs Found and Fixed

### Bug 1: Rate parsing returns 0 for all items
- **Symptom**: All stock items showed `rate: 0` in sync output
- **Root cause**: `_parseRate()` regex `[₹$,\/\w\s]+$` — `\w` matches digits, so `350/Nos` got stripped to empty string
- **Fix**: Simplified to `str.replace(/[₹$\s,]/g, '')` then extract number with `/-?[\d.]+/`
- **Verified**: 350/Nos → 350, ₹ 1,200.50/Nos → 1200.5, ₹ 150.00 → 150

### Bug 2: Tray popup Sync Now button always disabled
- **Symptom**: Button appeared greyed out and unclickable
- **Root cause**: Condition `!data.registered || !data.tallyStatus.connected` — agent not registered with cloud API key during local testing
- **Fix**: Removed `!data.registered` check — Tally sync is a local operation, doesn't require cloud registration

### Issue 3: Stock groups failed to load (XML escaping)
- **Symptom**: "Failed to load stock groups" in UI
- **Root cause**: Mock server returned unescaped `&` in "Tools & Equipment" group name, causing xml2js parse error
- **Fix**: Added `escapeXml()` helper to mock server. Not a production bug (Tally returns properly escaped XML), but worth noting as a defensive measure.
